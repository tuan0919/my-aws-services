# So sánh giữa các dịch vụ lưu trữ
- **S3**: Object Storage.
- **S3 Glacier**: Object Archival
- **EBS volumes**: Ổ cứng trên mạng có thể gắn vào một EC2 instance tại một thời điểm.
- **Instance Storage**: Ổ cứng vật lý có thể gắn vào EC2 instance (có IOPs cực cao).
- **EFS**: Hệ thống File System trên mạng cho các instance Linux hoặc POSIX Filesystem.
- **FSx cho Windows**: Hệ thống File System trên mạng cho hệ thống Windows server.
- **FSx cho Lustre**: Hệ thống File System dành cho các Linux file system yêu cầu hiệu suất cao.
- **FSx cho NetApp ONTAP**: Hệ thống File System hỗ trợ nhiều hệ điều hành khác nhau.
- **FSx cho OpenZFS**: Hệ thống File System dành cho ZFS.
- **Storage Gateway**: S3 & FSx File Gateway, Volume Gateway, Tape Gateway.
- **Transfer Family**: Giao diện FTP, FTPS, SFTP trên AWS S3 hoặc AWS EFS.
- **Data Sync**: sync dữ liệu từ cơ sở hạ tầng đến AWS hoặc từ AWS đến AWS.
- **Snowcone / Snowball / Snowmobile**: dùng để di chuyển một lượng lớn dữ liệu lên đám mây một cách vật lý trong trường hợp không có kết nối mạng.
